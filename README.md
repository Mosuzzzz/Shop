# GoShop 🛍️

A simple shop backend written in **Go**, created for learning and expanding real-world web development skills.

---

## 📌 About This Project

This project was built to practice **file-based data storage**, Go language fundamentals, and basic backend structure.

It uses `save.json` to store shop data — easy to understand, modify, and extend later into a real database system.

---

## ✨ Features

- Store and manage product data
- JSON file persistence (no database needed)
- Easy to improve and add more features
- Simple & readable Go code for beginners

---

## 🧰 Tech Stack

| Technology | Use |
|-----------|-----|
| Go        | Backend core logic |
| JSON File | Data storage |

## 🚀 Getting Started

### 1️⃣ Install Go (if not already)
👉 Download from: https://go.dev/dl/

### 2️⃣ Clone the repository  
```bash
git clone https://github.com/Mosuzzzz/GoShop.git
cd GoShop
```

###3️⃣ Run the project
```bash
go run .
```

###📂 Project Structure
```bash
GoShop/
├── backdoor.go     # Main backend logic
```
